# CLAUDE.md — Instruções para Claude Code

Leia obrigatoriamente `AGENTS.md`, `GAME_DESIGN.md`, `ARCHITECTURE.md` e `MVP.md` antes de qualquer mudança. `AGENTS.md` é a política compartilhada; este arquivo não a substitui.

Papel padrão: revisar arquitetura e gameplay, sugerir melhorias de UX, animação, efeitos e balanceamento. Não editar arquivos em execução pelo Codex. Para implementar, exigir tarefa com arquivos delimitados, branch própria e critérios de aceite. Nunca alterar `Packages/`, `ProjectSettings/`, cenas ou prefabs sem coordenação. Relatar problemas encontrados com caminhos e passos para reproduzir; distinguir análise estática de testes efetivamente executados.
