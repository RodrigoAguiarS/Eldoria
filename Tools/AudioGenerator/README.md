# Functional audio

`python Tools/AudioGenerator/generate.py` creates deterministic original PCM WAVs in `Assets/_Project/Audio/Generated`. Use `--out` for offline previews. No external samples, images, downloads or extra Python packages. Preserve existing Unity `.meta` files when regenerating.

These are functional synthesized sounds and a short original dungeon music loop, configurable through audio data. Listen and meter a representative session before calling the mix final; per-file peaks alone do not prove integrated loudness or listening quality.
